# Super Shop Sales Management System

A Java Swing-based desktop application developed to simulate the sales and billing operations of a super shop.

This project demonstrates Object-Oriented Programming (OOP) concepts through a graphical user interface for managing products, stock, customers, sales transactions, and payment receipts.

## Features

- Java Swing-based graphical user interface
- Product management with multiple categories
- Dynamic product selection
- Add, edit, and remove products from cart
- Quantity management
- Automatic stock availability checking
- Stock adjustment after transactions
- Customer information management
- Automatic bill calculation
- Discount calculation based on purchase amount
- Payment confirmation system
- Automatic receipt generation
- Receipt saved as a text file with:
  - Customer details
  - Purchased products
  - Quantity and price
  - Total amount
  - Discount
  - Final payable amount

## How It Works

1. Enter customer information.
2. Select products from different categories.
3. Add products to the shopping cart.
4. Modify quantities or remove items if needed.
5. Confirm purchase.
6. System calculates total price and discount.
7. A payment receipt is generated automatically.
